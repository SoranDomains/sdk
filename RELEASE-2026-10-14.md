# October 14 signing fixes

Holder **0.10.1** and Owner **0.12.1** were published on **14 October 2026**.
Their downloaded npm archives match the reviewed releases. Lookup remains
**0.11.0**. MCP **0.10.1** is prepared; its npm publication remains pending.

Holder and Owner validate that simulated legacy account-signed writes match the
requested source, operation, contract, method and arguments. Unexpected
authorizers, extra roots and nested calls are rejected before signing.
Permissionless upkeep accepts no authorization. Holder uses the configured
contract-wallet holder identity for network-address writes and keeps
permissionless upkeep on its fee payer without requesting wallet authorization.

MCP 0.10.1 pins both fixed SDKs, validates legacy authorization again at its signing
boundary, and serializes write execution for each payer. Native claim payments use
their dedicated authorization and fee checks. The native-signup reference uses
published Holder 0.10.1.

MCP source matches `60325a41ea2e7820272c8e8d3a9c827122ab5d62`. Exact mappings, retained public
tests, private-only source-CI obligations and verified core dependency integrity

separate rollout. The October 1 publication records remain historical evidence.
