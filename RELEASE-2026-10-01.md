# October 1 SDK release candidate

Publication is pending. This source prepares:

| Package | Candidate |
| --- | --- |
| `@sorandomains/lookup` | 0.11.0 |
| `@sorandomains/owner` | 0.12.0 |
| `@sorandomains/holder` | 0.10.0 |

The packages add one level of parent-controlled subnames, namespace-wide creation
and suspension policy, independently configured receiving destinations, and
network address records. Ownership generation and parent lifetime checks protect
child records from stale ownership. Existing namespaces need their owner's
contract upgrade before these capabilities become available.

The release also carries the reviewed signing, fee, contract-policy, payment and
upgrade checks, plus bounded hint fetch handling that works in browser and worker
runtimes. Direct Registry mode rejects child detail and identity reads that need
Universal Lookup rather than invoking an incompatible ABI. Node 22.12 or later
and Stellar SDK 17.x are required.

All production core SDK files match the source revision recorded in [SYNC.md](SYNC.md).
Portable public tests and the required monorepo integration gates are listed in
[test-manifest.json](test-manifest.json). The public fixtures contain ABI metadata
and artifact hashes, not private contract or API source.

MCP is a second stage: this mirror retains its existing MCP **0.9.5** source while
npm currently serves **0.9.6**. MCP **0.10.0** will be prepared after the three core
versions are published, using exact registry dependencies. The hosted MCP is a
separate deployment and is not changed by this candidate.
